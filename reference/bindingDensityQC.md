# 

     Quality control - Binding density 

nSolver binding density quality flag identified in the nSolver manual
Scripts copied from
https://github.com/bhattacharya-a-bt/NanoNormIter/tree/master/R Citing
https://www.ncbi.nlm.nih.gov/pmc/articles/PMC8138885/

## Usage

``` r
bindingDensityQC(rcc, low, high)
```

## Arguments

- rcc:

  loaded and valid rcc file

- low:

  the lower limit for binding density

- high:

  the upper limit for binding density

## Value

A character of 'Flag' or 'No flag' for binding density quality
