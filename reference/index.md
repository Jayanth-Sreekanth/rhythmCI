# Package index

## Core Calculations

Main functions for computing rhythm confidence intervals.

- [`rhythmicity()`](https://jayanth-sreekanth.github.io/rhythmCI/reference/rhythmicity.md)
  : Rhythmicity analysis using Harmonic Regression and bootstrapping

## Data Loading and Normalization

Functions for importing raw rhythm data and applying normalization. Use
`normalization = "none"` to load raw datasets directly.

- [`loadnormalizercc()`](https://jayanth-sreekanth.github.io/rhythmCI/reference/loadnormalizercc.md)
  : Load and Normalize Nanostring gene expression data
- [`normalizeruvg()`](https://jayanth-sreekanth.github.io/rhythmCI/reference/normalizeruvg.md)
  : Normalize Nanostring gene expression data

## Visualization

Relative Log Expression (RLE) plots.

- [`create_RLEplot()`](https://jayanth-sreekanth.github.io/rhythmCI/reference/create_RLEplot.md)
  : Create a RLE plot customized to time-series data

## Package Datasets

Built-in datasets included with the package.

- [`simdf`](https://jayanth-sreekanth.github.io/rhythmCI/reference/simdf.md)
  : Simulated Data Frame using simphony
