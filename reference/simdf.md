# Simulated Data Frame using simphony

A sample data frame with 10 genes (columns) and 35 samples from five
subjects (rows)

## Usage

``` r
data(simdf)
```

## Format

Time-series gene expression data frame:

- rows:

  35 measurements sampled at 4-hour intervals for five Subjects (P1, P2,
  P3, P4, P5)

- columns:

  10 genes

## Examples

``` r
data(simdf)
```
